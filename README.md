# SpendWise – Flutter Front-End

SpendWise is a cross-platform personal expense management front end developed for ICT725 Assessment 4. It follows the Assessment 3 high-fidelity prototype and implements the two core front-end functions required for this assessment:

1. Add Expense – validated expense entry with title, amount, category, date and notes.
2. Budget Tracking – editable monthly budget with progress indicators and category budgets.

It also includes Dashboard, Transactions and Spending Report screens so the major navigation flow can be demonstrated.

## Run
Install Flutter 3.x, then run:
```bash
flutter pub get
flutter run
```
Select an Android emulator for the assessment presentation.

The application currently uses in-memory demo data. No external database or authentication service is included because this assessment focuses on the front end.
