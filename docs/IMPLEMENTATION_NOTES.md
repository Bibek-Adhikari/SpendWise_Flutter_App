## Assessment 4 implementation notes

The app follows the SpendWise prototype structure: Login, Dashboard, Add Expense, Transactions, Budget and Report. The implementation improves the prototype based on the Assessment 3 feedback by using larger readable text, clearer category icons, a prominent Add Expense action, explicit budget labels and a visual spending report.

### Demonstrable functions
- Add a new expense and see it immediately reflected on Dashboard, Transactions, Budget and Report.
- Edit monthly budget and see the progress/remaining amount update.

### Not implemented
- Production authentication and account creation backend.
- Persistent database/cloud sync.
- Real income entry.
- Advanced report filters.
- Production security/password storage.
